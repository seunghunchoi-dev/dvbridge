DVBridge 추가 설치 안내
========================

DVBridge 본체만 설치하면 바로 실행됩니다. 따로 깔아야 하는 프로그램(런타임 등)은 없습니다.
아래는 쓰는 기능에 따라 더 준비하는 것들입니다. 위에서부터 차례로 보세요.


[1] 보코더 플러그인 — DMR 음성을 쓰려면 꼭 필요 (직접 구하기)
-----------------------------------------------------------
- 하는 일: DMR 음성(AMBE+2)을 압축하고 복원합니다. 없으면 접속은 되지만 소리가 나지 않습니다.
- DVBridge에는 들어 있지 않고, 함께 나눠 드리지도 않습니다.
  사용하시는 분이 직접 구하시고, 그 라이선스·특허 조건도 직접 확인해 주세요.
- 파일 이름: vocoder_*.dll  (함께 받은 라이선스·고지 문서도 같이 두세요)
- 넣는 방법 (둘 중 하나)
  ① DVBridge 설치 중 "보코더 플러그인 (선택)" 단계에서 [찾아보기]로 그 파일을 고릅니다.
  ② 설치한 뒤 시작 메뉴 → DVBridge → "보코더 폴더 열기"(C:\Program Files\DVBridge\plugins)에 파일을 넣고
     DVBridge를 다시 시작합니다.
     ("관리자 권한이 필요합니다" 창이 뜨면 [계속]. 포터블판은 프로그램 폴더의 plugins 폴더)
- 확인: 웹 설정 → "보코더" 칸에 플러그인 이름과 보코더 폴더가 나오면 됩니다.


[2] 휴대폰 앱 — 휴대폰으로 교신하려면 필요 (무료)
--------------------------------------------------
- DVSwitch Mobile (안드로이드): 구글 Play 스토어에서 "DVSwitch Mobile"을 찾아 설치합니다.
- 설정 방법은 사용 설명서 7장(휴대폰 설정)을 보세요.
  Hostname = 이 PC 주소, TX Port = 그 사용자의 USRP 포트, Port = 34001


[3] 음성 팩 (자연스러운 목소리) — 선택
-------------------------------------
- 하는 일: 브릿지 공지를 사람처럼 자연스러운 한국어 목소리(여성 5·남성 5)로 읽어 줍니다.
  없어도 Windows 기본 목소리로 읽어 줍니다.
- 파일: DVBridge-voicepack-0.1-setup.exe  (약 360MB, 설치하면 약 400MB)
- 설치: DVBridge를 먼저 설치한 뒤 실행합니다. 설치된 DVBridge를 스스로 찾아 넣고,
  켜져 있던 DVBridge는 다시 켜 줍니다.
- AI 음성 모델(Supertonic 3, Open RAIL-M 라이선스)을 쓰므로
  설치할 때 한 번, 웹 설정 → 브릿지 공지 → "사용 제한" 칸에서 한 번 동의해야 쓰입니다.
  이 목소리로 만든 공지는 휴대폰에 "브릿지 공지 (AI 음성)"으로 표시됩니다.
- 따로 제거하지 않아도 DVBridge를 제거하면 함께 지워집니다.


[4] 인터넷에서 받는 것 — 설치 필요 없음
--------------------------------------
- RadioID 명단(콜사인·이름 표시): 웹 설정 → "ID 명단" 칸의 [RadioID 명단 받기]를 누르면 radioid.net에서 받아 옵니다.
- BrandMeister 접속: 사용자마다 BrandMeister SelfCare에서 정한 "핫스팟 보안 비밀번호"가 필요합니다.


[5] 다른 PC·휴대폰에서 웹 설정을 열려면
--------------------------------------
- DVBridge를 처음 실행할 때 나오는 Windows 방화벽 창에서 [허용]을 눌러 주세요.
- 밖(LTE·5G)에서 쓰려면 공유기 포트 포워딩이 필요합니다 (사용 설명서 13장).

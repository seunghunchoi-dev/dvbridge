DMRBridge 0.1 (Windows 64비트)
==============================

BrandMeister 등 DMR 마스터(Homebrew 방식)에 접속해 DVSwitch Mobile 휴대폰과 음성을 이어 주는
아마추어 무선용 브리지 프로그램입니다. 여러 사용자 동시 접속, 웹 설정·대시보드(이력·실시간 듣기·서버 부하),
RadioID 명단으로 콜사인 표시를 지원합니다.

최초 제작: 최승훈 (6K2KZR)
라이선스: MIT (LICENSE) — 누구나 자유롭게 사용·수정·재배포할 수 있으며, 원저작자 표기를 유지해 주세요.

※ 아마추어 무선국 허가를 받은 분만 사용하세요.

사진과 함께 따라 하는 자세한 설명은 같은 폴더의 "사용 설명서.pdf"를 보세요.
설치판은 시작 메뉴 DMRBridge → 사용 설명서.


1. 처음 사용하는 순서 (3단계)
-----------------------------
① DMRBridge 를 실행하고 [웹 설정 열기]를 누릅니다. 브라우저가 열립니다.
② 웹 화면에서 관리자 비밀번호를 정합니다 (처음 한 번, 이 PC에서만 정할 수 있음).
③ [+ 사용자 추가]로 콜사인·DMR ID·핫스팟 접미사·핫스팟 비밀번호·USRP 포트를 넣고 저장한 뒤 [서비스 켜기].
   - BrandMeister 마스터 포트는 모든 핫스팟이 62031 입니다.
   - 사용자마다 달라야 하는 것: USRP 포트, 핫스팟 접미사(핫스팟 ID)
그다음 휴대폰 DVSwitch Mobile: Hostname = 이 PC 주소, TX Port = 그 사용자의 USRP 포트, Port = 34001
토크그룹 변경: 휴대폰에서 번호# (예 450#). 에코 시험: 450997# (개인호출로 자동 변경)


2. 프로그램 화면 (간단 제어판)
------------------------------
- [서비스 켜기/끄기]: 모든 사용자의 BM 접속을 한 번에 켜고 끕니다.
- [웹 설정 열기]: 사용자 추가·편집·삭제, TG 바꾸기, 브릿지 공지, 네트워크 점검, 백업·복원, ID 명단 받기, 보코더 상태, 관리자 비밀번호 변경
- [대시보드 열기]: 송수신 상태·이력, 실시간 듣기, 서버 부하 (누구나 보기)
- 웹 접속 주소: "모든 네트워크"로 두면 같은 와이파이의 휴대폰에서도 웹 설정·대시보드를 열 수 있습니다.
- 자동 실행·복구:
  · Windows를 켜면 DMRBridge 자동 실행 (트레이로 시작)
  · DMRBridge가 켜지면 서비스 자동 시작
  · 와치독: 끊긴 접속을 15초마다 다시 켜고, 프로그램이 비정상 종료되면 자동으로 다시 실행
- 창을 닫으면 작업 표시줄 오른쪽(트레이) 아이콘으로 내려가 계속 동작합니다.
  완전히 끝내려면 [종료] 버튼이나 트레이 아이콘 메뉴의 [종료]를 누르세요.

2-1. 브릿지 공지 (휴대폰에 음성 안내)
------------------------------------
웹 설정의 "브릿지 공지"에서 이 브릿지에 접속한 휴대폰에만 음성으로 안내합니다. BM으로는 나가지 않습니다.
- 문장 읽어 주기: 문장을 쓰고 [지금 보내기] → Windows 기본 음성(한국어)으로 읽어 줍니다. 딩동 알림음·반복(1~3번) 선택
- 마이크로 바로 말하기: [방송 시작] → 말하기 → [방송 끝]
  (브라우저 보안 규칙 때문에 DMRBridge가 실행 중인 PC에서 http://localhost:포트/settings 로 열었을 때만 됩니다)
- 예약 공지: 시각·요일·문장·받을 사용자를 정해 두면 그때 자동으로 읽어 줍니다. [예약·목소리 저장]을 꼭 누르세요.
- BM 통화(수신)나 휴대폰 송신 중에는 기다렸다가 끝난 뒤 나가고, 도중에 통화가 끼어들면 멈췄다가 이어서 보냅니다.
- 휴대폰 화면에는 "브릿지 공지"로 표시됩니다. (음성 팩의 AI 목소리로 만든 공지는 "브릿지 공지 (AI 음성)")
- 소리 장치(이 PC): 마이크·스피커 고르기, 마이크 크기, [마이크 시험], 공지 [미리 듣기](휴대폰에는 안 보냄),
  "보낼 때 PC 스피커로도 듣기". 선택은 그 브라우저에 저장됩니다.
- 무전 교신 말투: 문장 속 호출부호는 포네틱으로(HL0EXM → 호텔 리마 제로 에코 엑스레이 마이크), TG 번호는 한 자리씩 읽습니다.
  읽는 방법(포네틱·영어 글자·한국어 숫자)과 발음 사전(CQ=씨큐 등, 고칠 수 있음)은 웹 설정 브릿지 공지 칸에서.
- 보내기 진행 표시: 음성 만드는 중(예상 시간) → 통화 끝나기를 기다리는 중 → 휴대폰으로 보내는 중(초)이 화면에 나옵니다.
- 자연스러운 목소리: 음성 팩(별도 설치 파일, 선택)을 설치하면 여성 5·남성 5 목소리로 읽어 줍니다.
  음성 팩의 AI 음성 모델은 사용 제한이 있어 웹 설정에서 동의해야 쓰입니다. 자세한 내용은 음성 팩의 README.


2-2. 내부 채널 (BM으로 안 나가는 이 브릿지 안의 채널)
-------------------------------------------------
- 휴대폰에서 99# 을 누르면 내부 채널로 들어갑니다 (번호는 웹 설정 → TG 바꾸기 → 내부 채널에서 바꿈, 0이면 끔).
- 내부 채널에서 말하면 BM으로는 나가지 않고, 이 브릿지에서 같은 내부 채널에 있는 사용자에게만 들립니다.
  BM 짧은 송신 제한과도 상관없습니다. 듣는 사람 화면에는 말한 사람 콜사인이 나옵니다.
- BM으로 돌아가려면 TG 번호# (예: 450#). 듣는 사람에게 BM 통화가 들어오면 BM이 먼저입니다.
- 대시보드 이력에는 "내부"로 남습니다.


3. 설치·업데이트·제거
---------------------
- 추가로 준비할 것(보코더·휴대폰 앱·음성 팩)은 같은 폴더의 "추가 설치 안내.txt"에 정리돼 있습니다.
- 추가 기능은 따로 내려받아 설치합니다:
  · 음성 팩(자연스러운 목소리, 선택): DMRBridge-voicepack-0.1-setup.exe 를 실행하면 설치된 DMRBridge 폴더를 찾아 넣습니다.
    AI 음성 모델 라이선스에 동의해야 설치됩니다. DMRBridge를 제거하면 함께 지워집니다.
  · 보코더: DMRBridge와 함께 나눠 드리지 않습니다. 직접 구해서 설치 중 "보코더 플러그인 (선택)" 단계에서 고르거나
    시작 메뉴 "보코더 폴더 열기"에 넣으세요 (5장).
- 설치판: DMRBridge-0.1-setup.exe → C:\Program Files\DMRBridge, 시작 메뉴·바탕 화면 바로 가기
- 포터블판: DMRBridge-0.1-win64.zip 을 원하는 폴더에 풀고 DMRBridge.exe 실행 (설치 불필요)
- 새 버전 설치 파일을 그대로 실행하면 같은 위치에 업데이트됩니다. data(설정)와 plugins(보코더)는 그대로 남습니다.
- 제거할 때 설정(data)까지 지울지 묻습니다. 기본은 "남겨 둠"입니다.


4. 설정 저장 위치·백업·보안
---------------------------
- 설정·이력·명단·로그는 프로그램 폴더 안 data 폴더에 저장됩니다 (예: C:\Program Files\DMRBridge\data).
- 핫스팟 비밀번호는 Windows(DPAPI)로 암호화해 저장하고, 프로그램·웹 어디에도 다시 표시하지 않습니다.
  같은 PC의 같은 Windows 계정에서만 풀립니다. 다른 PC에서 복원하면 비밀번호만 다시 입력하세요.
- 웹 관리자 비밀번호는 해시로만 저장합니다. 5번 틀리면 5분간 잠깁니다.
- 설정을 바꿀 때마다 data\backup 에 자동 백업(최근 20개)이 남습니다. 웹 설정에서 내려받기·복원할 수 있습니다.
- 웹은 HTTPS가 아니므로 비밀번호 입력은 이 PC나 믿을 수 있는 네트워크(집 와이파이 등)에서 하세요.
- 예전 버전(%APPDATA%\DMRBridge)에 설정이 있으면 처음 실행할 때 자동으로 옮겨 옵니다.


5. 보코더 (음성 압축·복원)
--------------------------
DMR 음성(AMBE+2)을 쓰려면 보코더 플러그인(vocoder_*.dll)이 필요합니다.
DMRBridge에는 보코더가 들어 있지 않으며, 함께 배포하지도 않습니다. 사용하시는 분이 직접 구하시고,
그 라이선스·특허 조건(AMBE+2는 DVSI의 특허 기술)도 직접 확인해 주세요.
- 설치판: 설치 중 "보코더 플러그인 (선택)" 단계에서 가지고 있는 플러그인 파일을 고르면 함께 설치됩니다.
- 나중에 넣기: 시작 메뉴 "보코더 폴더 열기"(포터블판은 plugins 폴더)에 플러그인 파일을 넣고 DMRBridge를 다시 시작합니다.
  (Program Files 안이라 "관리자 권한이 필요합니다" 창이 뜨면 [계속]을 누르세요.)
- 플러그인과 함께 받은 라이선스·고지 문서를 확인하세요.
- 보코더가 없으면 시작할 때 경고가 나오고, 음성 없이(무음) 동작합니다.


6. BrandMeister 차단 방지
-------------------------
BM 루프 방지 규칙(60초 안에 2초 미만 송신 6번이면 1시간 차단)에 걸리지 않도록,
같은 DMR ID 기준으로 짧은 송신 5번까지만 허용하고 6번째는 막습니다.
채널을 바꾸기 전에는 TG 4000(Unlink)을 자동으로 보냅니다.


7. Windows 방화벽·백신
----------------------
- 휴대폰·다른 PC에서 접속하려면 처음 실행할 때 Windows 방화벽 허용 창에서 "허용"을 눌러 주세요.
- 코드 서명이 없는 새 프로그램이라 백신(V3 등)이나 Windows SmartScreen이 경고할 수 있습니다.


8. 함께 들어 있는 다른 소프트웨어
---------------------------------
Qt 6 (LGPL v3), MinGW-w64 GCC 런타임 — THIRD_PARTY_NOTICES.txt 와 LICENSES 폴더를 참고하세요.
